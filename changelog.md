**Blocky Outline v1.1.1** for **Minecraft 1.21.11** (Fabric). Lightweight and built with Fabric API.

**What's new in version 1.1.1:**

- Added dual-color fill gradient — blend two colors vertically inside the block fill
- Added in-game color picker modal with 2D SV picker, hue strip, and HEX input
- Added HEX color input directly on the color row
- Fixed outline alignment on grass, flowers, ferns, and other offset blocks
- Improved responsive UI — adapts cleanly to any window size or GUI scale
- Optimized render path: zero per-frame allocations, skip render when fully transparent
