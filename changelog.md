# What's New in v1.1.1

- **Dual-Color Fill Gradient**: Blend two vertical colors inside block fill with customizable Top and Bottom colors.
- **Interactive Color Picker Modal**: Added in-game 2D SV color picker with hue slider and live HEX color code input.
- **Dedicated Keybind Category**: Registered "Blocky Outline" category under Minecraft Options > Controls > Key Binds.
- **Offset Block Alignment Fix**: Fixed outline and fill alignment on model-shifted blocks (grass, flowers, ferns).
- **Responsive UI Layout**: Settings menu automatically adapts cleanly to all window sizes and GUI scales.
- **Render Optimizations**: Zero-GC per-frame allocations and rendering bypass when opacity is set to 0.
- **Minecraft 1.21.11 Compatibility**: Updated camera tracking and render pipeline for Fabric 1.21.11.
